# 模拟器业务验证（2026-10-28）

环境：DevEco Studio 内置 nova 15 Pro 模拟器，hdc 127.0.0.1:5555；本地模拟接口 192.168.124.2:3000。

## 已验证
- 安装签名 debug HAP，保留登录状态加载任务列表。
- 从设置退出并以 demo 模拟账号重新登录，成功进入任务列表。
- 任务 100017：两类提货照片各一张，通过页面完成提货，后台状态为 2。
- 同任务交货凭证两张、交货照片一张，通过页面完成交货，显示交货成功，后台状态为 4。
- 交货过程中短暂关闭接口后恢复，系统上传重试后完成操作。
- 三张交货图片均返回 HTTP 200、image/jpeg，大小分别为 46261、40181、46261 字节。
- 任务 100021：持续停止接口后发现旧版系统上传超过一分钟仍重试，页面持续加载。
- 修复：每张上传增加 30 秒应用层超时；超时取消系统上传任务、解除监听并拒绝 Promise。
- 修复版安装后复测：接口持续停止，35 秒检查时加载框已消失，两张已选照片保留，提货按钮恢复可点击；后台仍为待提货（1）。
- 恢复接口后双击提货，页面正常转为交货操作，后台任务 100021 为在途（2），保存两张提货图片。
- 模拟接口重启后，任务 100017 的交付状态和照片仍保留。
- 最终 debug HAP 构建成功。

- 未覆盖真实回单文字清晰度、定位导航、电话、极大图片、所有设备型号及所有异常分支。
- 双击未观察到重复业务效果；未进行服务端请求次数审计。
