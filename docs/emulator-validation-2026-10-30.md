# 模拟器验证记录（2026-10-30）

环境：DevEco nova 15 Pro，HarmonyOS 6.0.2 / API 22，hdc 127.0.0.1:5555。安装 entry-default-signed.hap，连接本机 3000 端口接口。

## 已验证

- 消息入口显示公告与任务通知；公告详情显示正文、创建时间，后端已读状态可查询。
- 任务通知可跳转到对应作业单详情，界面任务编号为 100035；分类全部已读后，后端19条任务通知均为已读。
- 任务通知滑动加载第二页并到达最后一条100005，“没有数据啦”完整显示在底部标签栏上方。修复消息页与列表未分配剩余高度导致底部遮挡的问题。
- 车辆页显示车牌、车型、所属机构和载重。停止接口后页面仍可操作；恢复接口、重新进入后可正常加载。
- 任务统计正常显示15条任务、1条完成任务和20公里；断连接口后等待26秒，加载框关闭，未知数值显示“--”。恢复接口后选择另一月份，请求成功，显示该月的0值统计。
- 任务详情截图连续三次打开并关闭，第三次预览截图经过人工图像检查，图片可见、非黑屏。
- entry debug HAP 构建及签名通过，最终构建日志为 BUILD SUCCESSFUL in 19 s 247 ms。
- Node 内置测试3项通过：展示数据迁移、消息/车辆契约与持久化、原有任务及图片上传完整流程。测试使用隔离数据库和随机端口。
